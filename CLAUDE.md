# CLAUDE.md — working rules for this project

Guidance for any AI agent working in this folder: Claude Code, Gemini Antigravity, or otherwise.

---

## What this project is

Business research and a commerce build specification for **Eternity Products** — a Nepal-based importer and distributor of professional hair styling tools, cosmetics and salon equipment (brand: Ikonic, imported from India).

Two customer types, two economics:

- **D2C retail** — styling tools. High volume, 25–30% margin, mostly cash on delivery.
- **B2B salon accounts** — parlours buying tools in bulk and salon furniture in high-value single units, ~50% margin. There is an existing base of parlour customers; they are an installed base, not a lead list.

---

## The rule that matters most

**Never invent a price, SKU, product link, or statistic.**

This project's entire value is that its numbers are traceable. Every price was read from a live page or computed from one, and every row carries a confidence tag saying which.

If you cannot verify something:

1. Say so explicitly, in the artefact itself
2. Tag it `NEEDS-SUPPLIER-INPUT`, `NOT VERIFIED`, or `CONFIRM`
3. Leave the structure ready so it fills in later
4. Never fill a gap with a plausible-looking guess

A blank the user can fill beats a wrong number they trust.

### Confidence tags

| Tag | Meaning |
|---|---|
| `VERIFIED` | Read from a live page during research; URL recorded |
| `LIKELY-MATCH` | Name-matched across sources, not exact — needs human confirmation |
| `NO-NEPAL-LISTING` | Real product, no Daraz Nepal equivalent found. The opportunity, not a gap |
| `NEEDS-SUPPLIER-INPUT` | No public data exists; awaiting the user's supplier list |
| `CONFIRM` | Found, but the user should check against their own account or agent |

## Conventions

**Currency.** NPR only. Format `NPR 12,920` or `रु 12,920`. Never `$`. In code, money is **integer paisa** (NPR × 100) — never floats.

**Exchange rate.** NPR is pegged to INR at **1.60**. Fixed since 1993, but treat as an input cell, not a constant.

**VAT.** 13%, charged on CIF + customs duty. Consumer prices display VAT-inclusive; B2B invoices itemise it.

**Confidential data.** `cost_npr`, margin percentages and distributor discounts must never reach a public API response, a customer-facing page, or a non-owner role. The `Margin Vault INTERNAL` sheet and the PDF are deliberately different: the PDF shows margin bands and outcomes, never supplier costs.

**Payments.** Stripe and PayPal **cannot receive money in Nepal**. Never suggest them. Use COD (primary), eSewa, Khalti, Fonepay, bank transfer.

**Identity.** Phone number, not email. Normalise to `+977` and strip spaces before comparison.

**Delivery.** Inside vs outside Kathmandu valley is a core pricing dimension, resolved from district — never free-typed.

**Festival dates.** Teej, Dashain and Tihar follow the Bikram Sambat lunar calendar and shift annually. Always describe them as approximate windows and tell the user to confirm on the patro. Never state a specific date as fact.

## Writing style for user-facing artefacts

Direct and concrete. Name the number, the file, the action.

- No em dashes
- Avoid: delve, crucial, robust, comprehensive, nuanced, multifaceted, leverage, unlock, seamless
- Short paragraphs. Lead with the finding, then the evidence
- Nepali-language content uses Roman script mixed with Nepali, the way people actually type on TikTok Nepal — not formal Devanagari, unless the context is a printed document
- State uncertainty plainly rather than hedging everything

## Generated artefacts

Spreadsheets and documents here are **generated by scripts**, not hand-edited. If a number is wrong, fix the generator and rebuild — a hand-edit is silently lost on the next run.

**Spreadsheets (openpyxl):**

- Arial throughout. Header fill `#1F3A5F`, white bold text. Title 16pt bold `#1F3A5F`, subtitle 9pt `#555555`
- Blue fill `#DCE9F7` = user input. Grey `#F2F2F2` = formula. Green `#E8F5E9` = result. Red `#FDE7E7` = warning
- Freeze panes and autofilter on the first table of each sheet only — a sheet has one of each, and a second header block claiming them breaks the first
- **Never hard-code row numbers in formulas.** Assign rows during layout, then resolve `{key}` placeholders. Section headers and spacers shift the layout and a hand-counted reference silently points at the wrong cell
- Live formulas, never baked values

**PDF:** markdown → styled HTML → headless Chrome `--print-to-pdf`. No PDF library needed.

**Deck:** `pptxgenjs`. Set `pres.layout` before adding slides. Hex colours without `#` and without alpha. Validate after writing.

**Verification:** openpyxl writes formulas but never computes them, so a workbook can look perfect and be arithmetically broken. `check_workbooks.py` evaluates the formula chain and asserts the invariants. Run it after any change to the generators.

## Facts established by research

Do not re-derive these; they were verified.

- Ikonic India catalogue: **320 SKUs** with list and MRP pricing, from the official Shopify product feed
- **Ikonic manufactures salon furniture too** — barber chairs INR 79,600–84,000, shampoo stations INR 54,400–64,000, pedicure station INR 200,000. One supplier relationship covers both business lines
- Nepal street price runs **+17% to +53%** over India list at the 1.60 peg, measured across 19 matched SKUs
- **Professional salon equipment is effectively absent from Daraz Nepal.** Searches return office chairs and sub-NPR-2,000 consumer gadgets
- Nepal customs duty: 0–80% ad valorem on CIF. VAT 13% on (CIF + duty). SAFTA gives India-origin goods roughly 5% reduction where base duty ≤30%, 7% above — requires a certificate of origin
- Daraz takes roughly 1.7–6% commission on appliances plus ~1.25% payout fee
- TikTok Shop and creator monetisation are **not available in Nepal** — TikTok is traffic only
- Implied distributor discount is **~25% off India list on tools**, derived from the user's stated 25–30% margin against verified Daraz prices

### Still unverified

- **Silk Hair** — no public catalogue or Daraz listing under this brand name
- **Qween lipstick** — zero Daraz Nepal presence; "qween" returns unrelated Queen-branded products
- **7-in-1 hydrafacial machine** — no verified India price at professional grade
- Exact customs duty rates per HS line — needs the user's clearing agent
- Actual supplier invoice costs — every cost figure is currently derived
